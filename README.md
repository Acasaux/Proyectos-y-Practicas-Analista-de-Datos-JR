# Proyectos-y-Practicas-Analista-de-Datos-JR

## Gestion de BD, Creacion de BD y visualizaciones por PowerBi

Para este proyecto vamos a generar desde cero mi base de datos sobre los paquetes Prime en uno de mis videojuegos favoritos, Warframe.

Comencé con DrawSQL, una página de diseño especializada en diagramas, donde organicé las tablas, los datos que lleva cada una y sus tipos de datos. Consta de 9 tablas con varios tipos de datos, tratando de gestionar las medidas de almacenamiento necesarias sin exceder el volumen permitido. Tipos de datos utilizados: TINYINT, SMALLINT, VARCHAR(), DATE. Además, generé sus claves primarias y las claves foráneas necesarias.

Para la segunda etapa del proyecto, creé la base de datos utilizando código SQL en MySQL Workbench. Empecé por las bases de datos y fui generando por secciones los datos de mis tablas para lograr una mejor organización. A estos procesos los guardé en scripts SQL, para poder revisarlos cada vez que los necesite. Por último, generé un backup con todos los datos por cualquier error que pudiera ocurrir.

En la tercera etapa comencé a utilizar Power BI. Primero enlacé el servidor de MySQL Workbench para obtener los datos y empezar con el dashboard. Comprobé que el diagrama estuviera bien en la aplicación y luego generé dos tablas más en Power Query: una para las imágenes de cada Warframe y otra para el logo. Por último, generé un dashboard de prueba que luego descarté, quedándome con el segundo dashboard que hice. Incluí datos como: selector de personaje, foto del personaje, habilidades de cada uno, ventas realizadas por paquete, el logo y, por último, las estadísticas del personaje.
