# Proyectos-y-Practicas-Analista-de-Datos-JR

## Gestion de BD, Creacion de BD y visualizaciones por PowerBi

Para este proyecto vamos a estar generando desde cero mi base de datos sobre los paquetes prime en uno de mis videojuegos favoritos "Warframe".

Comenze con "Draw Sql", una pagina de diseño especializada en diagramas, en donde organice las tablas, los datos que lleve cada una y sus tipos de datos.
Consta de 9 tablas con varios tipos de datos, tratando de gestionar las medidas de almacenamiento necesarias sin exceder el volumen que contiene.
Tipos de datos: Tinyint, Smallint, Varchar(), Date.
Ademas genere sus claves primarias y las claves foraneas que necesite.

Para la segunda etapa del proyecto cree la base de datos utilizando codigo de SQL en "MySql Workbench". Empezando por las bases de datos y generando por secciones los datos de mis bases 
para una mejor organizacion. A estos procesos los guarde en scrips sql, para poder revisarlos cada vez que los necesite. Por ultimo genere un backup con todos los datos por cualquier error
que pueda ocurrir.

En la tercera etapa comenze a utilizar "PowerBi". Primero enlace el servidor de MySql workbench para obtener los datos y empezar con el dashboard.
